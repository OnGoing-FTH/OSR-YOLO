# 四阶段开集异常检测完整说明

本文把当前项目的四个阶段串成一个完整闭环，并逐项说明：每阶段做什么、输入和输出是什么、产物保存在哪里、被谁使用、所有关键特征/张量的维度、Phase 3 的正负样本与 Ignore 规则，以及 Phase 4 的未知异常推理规则。

本文描述的是当前实现，不额外引入伪框、第二轮 TAL 或“第 9 个 YOLO 类”。

---

## 0. 最终要解决的问题

系统需要同时处理两类结果：

1. **已知缺陷**：数据集已有人工类别标注的 8 类缺陷。它们继续由 YOLO11s-seg 主路输出类别、框、实例掩码和置信度。
2. **未知/未标注异常**：不强行归入现有 8 类，也不在主检测头中训练成第 9 类；由单独的 anomaly branch 输出异常概率图，再在推理后处理阶段生成 `unknown_anomaly`。

完整数据流：

```text
Phase 1：正常图 → 空间特征库 Bank_Spatial
Phase 2：训练图 + Bank_Spatial → A_208 异常先验图 + 阈值
Phase 3：图像 + 已知 polygon GT + A_208 → YOLO11s-seg + anomaly branch 训练
Phase 4：Phase 3 checkpoint + 任意待测图 → 已知类实例 + unknown_anomaly
```

关键前提：这是一个**固定工位 / 对齐产品**方案。训练和推理都把原始图像直接拉伸到 `832×832`，不使用 letterbox。这样 Phase 2 缓存的 `A_208.npy`、Phase 3 已知分割标签和 Phase 4 输出都共享同一个几何坐标系。

# Phase 1：构建固定工位正常空间特征库

## 3. Phase 1 的目的

Phase 1 只使用正常图像建立“该固定工位在每个空间位置通常长什么样”的基准库。

它不是训练 YOLO，也不生成检测框、不生成 mask、不做阈值判断。它只产出一个可供后续 Phase 2 查询的空间特征库。

输入目录：

```text
/home/fth/OSR-YOLO/Normal_images
```

当前正常图数量：

```text
N_ok = 20
```

## 4. Phase 1 特征产生过程与尺寸

每张正常图先直接拉伸到 `832×832`：

```text
输入图像 X_ok：N_ok×3×H0×W0
直接拉伸后：N_ok×3×832×832
```

随后进入冻结的 ImageNet 预训练 `wide_resnet50_2`。WRN50 不参与反向传播：

```text
所有参数 requires_grad = False
forward 在 inference_mode 下运行
```

### 4.1 WRN layer2 支路

```text
输入：N_ok×3×832×832
  ↓ stem + layer1 + layer2
layer2 原始输出：N_ok×512×104×104
  ↓ AvgPool2d(kernel=3, stride=1, padding=1)
layer2 平滑后：N_ok×512×104×104
```

池化 stride 为 1，因此空间尺寸仍然是 `104×104`。

### 4.2 WRN layer3 支路

```text
layer2 原始输出：N_ok×512×104×104
  ↓ layer3
layer3 原始输出：N_ok×1024×52×52
  ↓ AvgPool2d(kernel=3, stride=1, padding=1)
layer3 平滑后：N_ok×1024×52×52
  ↓ bilinear interpolate 到 layer2 的空间尺寸
layer3 对齐后：N_ok×1024×104×104
```

### 4.3 融合、压缩和归一化

两个尺度在 channel 维拼接：

```text
layer2：N_ok×512×104×104
layer3 aligned：N_ok×1024×104×104
  ↓ concat(dim=channel)
fused：N_ok×1536×104×104
```

当前实现不是可学习的 `1×1 Conv` 降维，而是无参数的自适应通道平均池化。每个空间位置独立处理：

```text
每位置：1536D 向量
  ↓ AdaptiveAvgPool1d(output_size=256)
每位置：256D 向量
```

恢复为特征图后：

```text
raw spatial feature：N_ok×256×104×104
  ↓ channel 维 L2 normalize
Bank_Spatial：N_ok×256×104×104
```

当前实际 artifact：

```text
Bank_Spatial：20×256×104×104，FP16 落盘
```

每个 `(y,x)` 位置对应一个 256D 单位向量；它仍保留固定工位上的空间含义。例如 `(y=40,x=60)` 的正常库向量只代表该位置附近的正常纹理/结构，而不是整张图的全局语义。

# Phase 2：异常先验图 A_208 与阈值标定

## 6. Phase 2 的目的

Phase 2 使用 Phase 1 的正常空间库，为每张训练图生成一个离线异常分数图 `A_208.npy`。

`A_208` 的含义是：

> 该位置的 WRN 局部特征与“同一固定空间位置的正常模式”有多不相似。

它不是 YOLO 类别概率，不是人工标签，不是实例 mask，也不是可直接用于 NMS 的检测分数。

## 7. 训练图 query 特征的产生

任意训练图的特征提取流程与正常库完全一致：

```text
训练图 X：B×3×H0×W0
  ↓ 直接拉伸
X_832：B×3×832×832
  ↓ WRN layer2
L2：B×512×104×104
  ↓ 3×3 AvgPool, stride=1
L2_smooth：B×512×104×104

L2：B×512×104×104
  ↓ WRN layer3
L3：B×1024×52×52
  ↓ 3×3 AvgPool, stride=1
L3_smooth：B×1024×52×52
  ↓ bilinear ×2
L3_align：B×1024×104×104

L2_smooth + L3_align
  ↓ channel concat
F_fused：B×1536×104×104
  ↓ 每位置 AdaptiveAvgPool1d(1536→256)
F_256：B×256×104×104
  ↓ channel L2 normalize
Q：B×256×104×104
```

其中 `Q[b,:,y,x]` 是 batch 中第 `b` 张图、`(y,x)` 固定空间位置的 256D 单位特征向量。

## 8. 局部空间正常匹配：如何得到 A_104

Bank 的维度为：

```text
Bank_Spatial：N_ok×256×104×104
当前：20×256×104×104
```

对于 query 的每个空间位置 `(y,x)`：

```text
query vector：Q[b,:,y,x]，维度 256
```

它只与正常库中相同位置加上 `3×3` 邻域的向量比较：

```text
Bank[n,:,y+dy,x+dx]
n ∈ [1, N_ok]
dy, dx ∈ {-1, 0, +1}
```

每个 query 位置的正常候选个数：

```text
N_ok × 3 × 3
= 20 × 9
= 180 个 256D 候选向量
```

相似度和异常分数的概念流程：

```text
Q[b,:,y,x]：256D
  ↔ 180 个 Bank 局部候选：180×256D
  ↓ cosine similarity
180 个相似度
  ↓ 取最大相似度（最接近的正常局部模式）
best_similarity[b,y,x]
  ↓ 变换为异常度（相似度越低，异常度越高）
A_104[b,0,y,x]
```

最终：

```text
A_104：B×1×104×104
```

## 9. A_104 如何得到 A_208

```text
A_104：B×1×104×104
  ↓ bilinear interpolate，空间放大 2 倍
A_208：B×1×208×208
```

每张训练图保存时移除 batch 维：

```text
单图文件内容：208×208，float16
训练时加载后：1×208×208，float32
batch collate 后：B×1×208×208，float32
```

## 10. 阈值如何得到

阈值在正常库上通过 Leave-One-Out（LOO）得到：每次取一张正常图作为 query，剩余正常图作为其 reference bank。

```text
正常库：20×256×104×104
第 i 次 LOO：
  query：1×256×104×104
  reference：19×256×104×104
  output：1×1×104×104
```

所有正常 LOO 分数汇总后计算：

```text
tau_low_base = normal pixel P99
tau_low = tau_low_base + 0.05
tau_high = tau_low + 0.20
```

当前实际数值：

```text
P99 / tau_low_base = 0.029670193791389465
tau_low            = 0.07967019379138947
tau_high           = 0.27967019379138947
```

阈值不是 Phase 4 的 `unknown_prob_threshold`：

| 阈值 | 所在空间 | 作用 |
|---|---|---|
| `tau_low` | `A_208` 教师异常分数空间 | Phase 3 中划分低异常负像素和可疑区域；ATL-Ignore 门限 |
| `tau_high` | `A_208` 教师异常分数空间 | Phase 3 中补充 teacher positive 像素 |
| `unknown_prob_threshold=0.50` | `anom_prob=sigmoid(anom_logits)` 模型输出空间 | Phase 4 中提取 unknown 连通域 |

它们数值虽然都在类似范围，但语义不同，不能互换。

# Phase 3：已知类 YOLO-seg + 开集异常监督训练

## 12. Phase 3 的目的

Phase 3 训练一个部署期只需 YOLO 模型本身就能运行的网络：

```text
输入图像：B×3×832×832
输出 1：8 个已知类的检测/实例分割结果
输出 2：B×1×208×208 的异常 logits/probability
```

Phase 1 的 WRN 和 Bank_Spatial 不被装进 Phase 3 checkpoint，也不要求部署时运行。它们的作用已经通过离线 `A_208` 传递给训练过程。

## 13. Phase 3 训练样本由什么组成

一个训练 batch 的关键字段如下：

| batch 字段 | 维度 | 来源 | 作用 |
|---|---:|---|---|
| `img` | `B×3×832×832` | 原图直接拉伸 | YOLO 输入 |
| `cls` | `N_inst×1` | 已知类标签 | TAL / 已知类分类 loss |
| `bboxes` | `N_inst×4` | 已知实例 box，归一化 `xywh` | TAL / box / DFL loss |
| `masks` | 常规实例分割 mask batch | 已知 polygon 标注 rasterize 后得到 | segmentation loss 与 known union mask |
| `batch_idx` | `N_inst×1` | 标记每个实例属于哪一张图 | 聚合实例、计算 segmentation loss |
| `anom_prior` | `B×1×208×208` | manifest 对应的 `A_208.npy` | anomaly loss 与 ATL-Ignore |
| `geom_valid` | `B×1×208×208` | 当前直接拉伸时全 1 | 保护未来存在无效 padding 的几何模式 |

`N_inst` 是这个 batch 内所有人工实例的总数，因此不是固定值。

## 14. 为什么必须关闭几何增强

`A_208.npy` 是在 Phase 2 中由原图直接拉伸到 `832×832` 后得到的。如果 Phase 3 对图像/标签做了任何未同步施加到 `A_208` 的几何变换，就会出现：

```text
图像中的缺陷在位置 A
人工 mask 在位置 A
A_208 高响应仍在旧位置 B
```

这样异常分支会接收错误监督，ATL-Ignore 也会屏蔽错误的检测点。

因此当前 Phase 3 强制关闭：

```yaml
mosaic: 0.0
mixup: 0.0
copy_paste: 0.0
cutmix: 0.0
degrees: 0.0
translate: 0.0
scale: 0.0
shear: 0.0
perspective: 0.0
fliplr: 0.0
flipud: 0.0
multi_scale: 0.0
```

这不是 YOLO 通常训练的最强增强设置，而是为了保证：

```text
img [B,3,832,832]
已知实例 mask / bbox
anom_prior [B,1,208,208]
```

之间的像素/空间语义严格对应。

## 15. Phase 3 模型特征流与输出尺寸

YOLO11s-seg 的常规检测 neck/head 在 `832×832` 输入下产生三个检测尺度：

```text
P3：B×128×104×104
P4：B×256×52×52
P5：B×512×26×26
```

> 上述 P3/P4/P5 channel 数来自当前 YOLO11s-seg head 的输入通道配置 `[128,256,512]`。检测 head 内部会进一步形成回归、分类与 mask coefficient 分支。

三尺度候选点数量：

```text
P3：104×104 = 10,816
P4： 52×52 =  2,704
P5： 26×26 =    676
---------------------
总计             14,196
```

### 15.1 标准已知类分支

在推理格式下，已知分支的原始输出是：

```text
known_predictions：B×44×14,196
```

其中 44 个通道由以下内容组成：

```text
4  个 box 参数
8  个已知类分数
32 个实例 mask coefficient
----------------
44 个通道
```

训练内部的回归/分类张量会以实现需要的布局保存，关键分类逻辑使用：

```text
pred_scores：B×14,196×8
```

即：每个候选点都有 8 个已知类的分类 logits。

### 15.2 Proto 分支与 anomaly branch

当前 Phase 3 不是直接从 `P3 [B,128,104,104]` 上接异常头，而是进入 Segment head 的 Proto 路径：

```text
P3 feature：B×128×104×104
  ↓ proto.cv1
中间特征：B×256×104×104
  ↓ proto.upsample，空间 ×2
中间特征：B×256×208×208
  ↓ proto.cv2
Proto 中间特征 F_proto：B×256×208×208
```

然后从同一个 `F_proto` 分两条支路：

```text
F_proto：B×256×208×208
  ├─ proto.cv3
  │    ↓
  │  prototype：B×32×208×208
  │    用途：标准实例 segmentation loss 与 Phase 4 的已知 mask 解码
  │
  └─ anom_head
       ↓ Conv 3×3，channel 256→64
     B×64×208×208
       ↓ Conv 1×1，channel 64→1
     anom_logits：B×1×208×208
```

异常分支不改变已有 8 类检测头的类别数；它只额外输出一个单通道像素级异常 logit 图。

## 16. Phase 3：已知 GT union mask 如何得到

人工标注通常包含多个实例，每个实例有自己的类别和 polygon mask。异常监督不需要区分这些已知类别，只需要知道一个像素是否属于任意已知缺陷。

将实例 mask 汇总为 union：

```text
实例 mask：每个实例一个空间 mask
  ↓ resize / 对齐到 anomaly 输出空间
每个实例：1×208×208
  ↓ 对同一图中的所有实例取 OR
M_known：B×1×208×208
```

定义：

```text
M_known[b,0,y,x] = 1
```

表示第 `b` 张图在 `208×208` 坐标 `(y,x)` 属于至少一个人工已知缺陷实例。

```text
M_known[b,0,y,x] = 0
```

只表示这里没有人工已知缺陷标注；它并不保证该像素“绝对正常”，因为可能存在未标注缺陷或未知类型缺陷。

## 17. Phase 3：异常分支正样本、负样本、Ignore 的精确定义

以下定义都在 anomaly output 空间中进行：

```text
A = anom_prior：B×1×208×208
M_known：B×1×208×208
G = geom_valid：B×1×208×208
Z = anom_logits：B×1×208×208
```

当前 direct-stretch 数据集内：

```text
G 全为 1，维度仍为 B×1×208×208
```

### 17.1 正样本（positive）

```text
positive = M_known OR (A > tau_high)
```

维度：

```text
positive：B×1×208×208，bool
```

正样本来源有两类：

| 正样本来源 | 判断条件 | 含义 | 当前状态 |
|---|---|---|---|
| 人工已知正样本 | `M_known=1` | 已被人工标注为任意已知缺陷的像素 | 始终可用 |
| 教师伪正样本 | `A > tau_high` | 与正常空间库差异显著的像素 | 当前为 0，见第 21 节 |

人工已知缺陷具有最高优先级：即使 `A_208` 在该位置很低，`M_known=1` 仍使该像素成为 anomaly positive。

### 17.2 负样本（negative）

```text
negative = NOT positive AND (A < tau_low)
```

维度：

```text
negative：B×1×208×208，bool
```

含义：该像素不是人工已知缺陷，也不是教师高置信异常，同时它的 WRN 异常先验低于正常容忍阈值，因此作为异常分支的可信负样本。

注意：如果一个像素 `A < tau_low`，但它属于 `M_known=1`，它仍然是 positive，因为 `positive` 的人工标签优先。

### 17.3 Ignore 像素

所有既非 positive 也非 negative 的像素进入 Ignore：

```text
ignore = NOT positive AND NOT negative
```

在常规情况下，Ignore 对应：

```text
tau_low ≤ A ≤ tau_high
且不在 M_known 内
```

维度：

```text
ignore：B×1×208×208，bool
```

它表达的是“不确定”：异常先验高到不适合作为正常背景负样本，但还没有高到适合作为教师正样本。

### 17.4 有效监督区域（valid）

```text
valid = (positive OR negative) AND G
```

维度：

```text
valid：B×1×208×208，bool
```

当前 `G=1` 时：

```text
valid = positive OR negative
```

未来若改为 letterbox 或存在 padding，可让 `G=0` 的区域完全不进入 anomaly loss，避免把无图像内容的 padding 区域错当作负样本。

### 17.5 监督 target

```text
target = float(positive)
```

维度：

```text
target：B×1×208×208，float32
```

取值：

```text
positive 像素：1.0
negative 像素：0.0
ignore 像素：target 虽可表示为 0，但会被 valid mask 排除，不产生 loss
```

### 17.6 像素类型汇总表

| 像素情形 | `M_known` | `A` 范围 | positive | negative | valid | target | 是否参与 anomaly BCE/Dice |
|---|---:|---|---:|---:|---:|---:|---|
| 人工已知缺陷 | 1 | 任意 | 1 | 0 | 1 | 1 | 是，正样本 |
| 高置信教师异常 | 0 | `A > tau_high` | 1 | 0 | 1 | 1 | 是，教师正样本 |
| 可信正常背景 | 0 | `A < tau_low` | 0 | 1 | 1 | 0 | 是，负样本 |
| 不确定区域 | 0 | `tau_low ≤ A ≤ tau_high` | 0 | 0 | 0 | 不计 | 否，Ignore |
| 无效几何区域 | 任意 | 任意 | 可能 | 可能 | 0 | 不计 | 否 |

## 18. Phase 3：Masked BCE 如何计算

异常分支输出：

```text
Z = anom_logits：B×1×208×208
```

使用未经 sigmoid 的 `Z` 计算数值稳定的 BCE：

```text
pixel_bce = BCEWithLogits(Z, target)
维度：B×1×208×208
```

只保留 `valid=1` 的位置：

```text
L_anom_bce =
  Σ(pixel_bce × float(valid))
  ───────────────────────────
  max(Σ float(valid), 1)
```

为什么必须 masked：

- 若直接在全图计算 BCE，Ignore 区域会被当作 target 0，模型会被强行训练成“中等异常也必须是正常”；这与开集目标冲突。
- `valid` 让人工已知缺陷和高置信教师区域提供正梯度，让低异常可信区域提供负梯度，让不确定区域不影响梯度。
- 分母至少为 1，避免极端 batch 中没有 valid 像素时出现除零。

## 19. Phase 3：Masked Dice 如何计算

先将 logits 变为概率，并再次施加 valid mask：

```text
P = sigmoid(Z) × float(valid)
T = target × float(valid)

P：B×1×208×208
T：B×1×208×208
```

对 batch 中每张图 `b`：

```text
intersection_b = Σ(P_b × T_b)
denominator_b  = Σ(P_b) + Σ(T_b)

dice_loss_b = 1 - (2×intersection_b + 1e-5) / (denominator_b + 1e-5)
```

Dice 的平均只包含存在至少一个正有效像素的图：

```text
positive_image[b] = (Σ T_b) > 0

L_anom_dice = mean(dice_loss_b for all positive_image[b] = true)
```

若整个 batch 没有正有效像素：

```text
L_anom_dice = 0，且保持零梯度
```

原因：纯负图像上 Dice 不适合作为主要背景损失，容易让 Dice 的分母行为主导优化；负样本监督由 `L_anom_bce` 负责即可。

## 20. Phase 3：总损失如何组成

标准 YOLO-seg 仍保留：

```text
L_box：已知类 box 回归损失
L_seg：已知实例分割损失
L_cls：8 个已知类的分类损失
L_dfl：Distribution Focal Loss 回归项
```

新增 anomaly 分支：

```text
L_anom_bce：B×1×208×208 的 masked BCE 标量
L_anom_dice：B×1×208×208 的 masked Dice 标量
```

总损失：

```text
L_total = L_box + L_seg + L_cls + L_dfl
          + lambda_anom × (L_anom_bce + L_anom_dice)
```

当前：

```text
lambda_anom = 1.0
```

重要边界：

```text
anomaly branch 不替代已知类分割。
已知类的 box / DFL / instance mask 仍只由人工已知标签及 TAL 正样本负责。
anomaly branch 的 208×208 像素监督只训练“异常在哪里”，不训练“异常属于哪一种新类别”。
```

## 21. 当前 teacher pseudo-positive 为什么为 0

当前 Phase 2 标定得到：

```text
tau_high = 0.27967019379138947
```

此前缓存训练图统计：

```text
训练图 A_208 最大值约为 0.1394
```

因此：

```text

teacher positive ratio = 0
```

也就是说，当前实际训练中：

```text

```

# Phase 3：TAL 与 ATL-Ignore 分类机制

## 22. TAL 负责什么

当前已知类检测仍使用 Ultralytics 的 Task-Aligned Assigner（TAL）。TAL 在三个检测尺度上为人工已知 GT 分配正候选点。

输入概念上包括：

```text
pred_scores：B×14,196×8
pred_boxes：B×14,196×4（解码后使用）
anchor_points：14,196×2
gt_labels：B×N_max×1
gt_boxes：B×N_max×4
```

输出中最关键的是：

```text
fg_mask：B×14,196，bool
```

解释：

```text
fg_mask[b,a] = true
```

代表第 `b` 张图的第 `a` 个候选点已经被 TAL 分配为某个**人工已知类** GT 的正样本。

TAL 继续决定已知类检测的正样本逻辑；anomaly prior 不改变 TAL 的分配过程。

## 23. A_208 如何映射到 P3/P4/P5

ATL-Ignore 需要判断每一个检测候选点附近是否有可疑异常先验。`A_208` 的空间比 P3/P4/P5 更细，因此采用 max pooling：

```text
A_208：B×1×208×208
  ↓ MaxPool2d(kernel=2, stride=2)
A_P3：B×1×104×104
  ↓ flatten
A_P3_flat：B×10,816

A_208：B×1×208×208
  ↓ MaxPool2d(kernel=4, stride=4)
A_P4：B×1×52×52
  ↓ flatten
A_P4_flat：B×2,704

A_208：B×1×208×208
  ↓ MaxPool2d(kernel=8, stride=8)
A_P5：B×1×26×26
  ↓ flatten
A_P5_flat：B×676
```

拼接顺序与检测头候选点顺序一致：

```text
A_flat = concat(A_P3_flat, A_P4_flat, A_P5_flat)
A_flat：B×14,196
```

max pooling 的意图：只要一个检测格点覆盖的 `A_208` 区域内存在较高异常响应，该格点就会保留该风险信号；这比平均池化更不容易稀释小异常。

代码会断言：

```text
A_flat.shape[1] == pred_scores.shape[1] == 14,196
```

以防 P3/P4/P5 排列或输入尺寸变化后，异常先验与检测候选点发生错位。

## 24. ATL-Ignore 如何改变分类 BCE

这里的 ATL-Ignore 指：**在 TAL 后，把“疑似异常但未被人工已知类 GT 分配”的候选点从背景分类 BCE 中忽略。**

定义：

```text
suspicious_negative = (NOT fg_mask) AND (A_flat >= tau_low)
```

维度：

```text
suspicious_negative：B×14,196，bool
```

分类 BCE 原始形式：

```text
bce_loss = BCE(pred_scores, target_scores)
bce_loss：B×14,196×8
```

其中：

```text
pred_scores：B×14,196×8
target_scores：B×14,196×8
```

构建权重：

```text
cls_weight：B×14,196×1
```

规则：

| 检测候选点情况 | `fg_mask` | `A_flat` | `cls_weight` | 分类 BCE 处理 |
|---|---:|---|---:|---|
| TAL 已知正样本 | 1 | 任意 | 1 | 保留标准已知类分类监督 |
| 普通可信背景 | 0 | `< tau_low` | 1 | 保留标准背景负监督 |
| 可疑未标注异常 | 0 | `≥ tau_low` | 0 | 不计入分类 BCE |

最终：

```text
L_cls = Σ[bce_loss × cls_weight] / max(Σ target_scores, 1)
```

`cls_weight` 的最后一维为 1，会广播覆盖该检测候选点的 8 个已知类 BCE 项。

### 24.1 ATL-Ignore 做了什么

```text
当 A_208 提示某区域可能异常，且 TAL 没有把它分配为人工已知类正样本时：
不要求 YOLO 主路把它学习成“8 个已知类全都不是”的背景。
```

这避免未标注缺陷或潜在未知缺陷在训练中被大量背景负样本梯度压制。

### 24.2 ATL-Ignore 不做什么

```text
不把 A_208 高分区变成已知类 GT。
不生成 pseudo box。
不生成 pseudo polygon / pseudo mask。
不将 A_208 输入 TAL 作为 GT。
不运行第二轮 TAL。
不改变 box loss 的正样本。
不改变 DFL loss 的正样本。
不改变 segmentation loss 的正样本。
不增加第 9 个训练类别。
```

因此，ATL-Ignore 是一个**分类负样本去压制机制**，不是开放词表分类器，也不是未知类检测框监督器。

# Phase 4：已知实例分割与 unknown_anomaly 推理

## 26. Phase 4 的目的

Phase 4 不再使用 WRN50、Bank_Spatial、`A_208.npy` 或 `tau_low/tau_high` 重新计算异常先验。

Phase 4 只加载 Phase 3 checkpoint，并对新图输出两条并行结果：

```text
已知路：8 类 YOLO-seg 实例
未知路：unknown_anomaly 连通域
```

输入新图：

```text
原始 BGR 图像：1×3×H0×W0（概念维度）
  ↓ cv2 resize，直接拉伸
模型输入：1×3×832×832，float32
```

## 27. Phase 4 模型前向输出

从包含 anomaly head 的 checkpoint 前向推理得到：

```text
known_predictions：1×44×14,196
proto：1×32×208×208
anom_logits：1×1×208×208
anom_prob = sigmoid(anom_logits)：1×1×208×208
```

逐项解释：

| 张量 | 维度 | 用途 |
|---|---:|---|
| `known_predictions` | `1×44×14,196` | 输入标准 NMS；44=`4 box + 8 class + 32 mask coefficient` |
| `proto` | `1×32×208×208` | 与 NMS 保留实例的 32D mask coefficient 相乘，解码 known mask |
| `anom_logits` | `1×1×208×208` | anomaly branch 原始输出 |
| `anom_prob` | `1×1×208×208` | sigmoid 后的异常概率，用于 unknown 提取 |

## 28. 已知类实例如何生成

### 28.1 NMS 输入与输出

NMS 输入：

```text
known_predictions：1×44×14,196
```

NMS 使用：

```yaml
conf_threshold: 0.25
iou_threshold: 0.70
max_det: 300
nc: 8
```

对某张图，NMS 后保留：

```text
predictions：M×38
```

38 个字段包括：

```text
4  个 box 坐标（xyxy，832 空间）
1  个 confidence
1  个 class_id
32 个 mask coefficient
-----------------
38
```

### 28.2 已知实例 mask 解码

```text
proto[0]：32×208×208
mask coefficient：M×32
box_832：M×4
  ↓ process_mask(..., upsample=True)
mask_832：M×832×832，bool
```

每一个 known 实例会输出：

```text
class_id：整数 0..7
class_name：对应已知类别名称
confidence：标量
bbox_xyxy_832：4 个浮点坐标

```

然后用独立横纵缩放系数映射到原图：

## 29. anomaly probability 如何变为 unknown_anomaly

### 29.1 为什么先删除 known 区域

异常分支可能对一个已知缺陷也给出高分。若直接对 `anom_prob` 做阈值和连通域，就可能出现同一个实体既被报告为：

```text
已知类：涂层划痕
unknown_anomaly：同一块区域
```

因此 Phase 4 先从异常图中移除已知实例区域。

### 29.2 known mask 在 208 空间的构建

已知实例的内部 mask：

```text
对每个实例：mask_832：832×832，bool
```

将每个 mask 以 nearest resize 缩放：

```text
mask_832：832×832
  ↓ nearest resize
mask_208：208×208
```

对所有 M 个已知实例取 OR：

```text
known_mask_208_raw：208×208，bool
```

再用椭圆结构元膨胀，默认半径 2 个 `208` 空间像素：

```text
kernel size = (2×2 + 1) × (2×2 + 1) = 5×5

known_mask_208：208×208，bool
```

膨胀的目的：覆盖 mask 边界、下采样误差和已知实例周围的小范围异常响应，减少已知与未知输出重叠。

### 29.3 residual anomaly

取 anomaly probability：

```text
anom_prob[0,0]：208×208，float32
```

复制并删除 known 区域：

```text
residual_anom：208×208，float32
residual_anom[known_mask_208] = 0.0
```

这一步之后：

```text
已知实例内部和其膨胀边界：0
非已知区域：保留模型异常概率
```

### 29.4 二值化、形态学和连通域

首先按模型输出概率阈值二值化：

```text
binary = residual_anom >= unknown_prob_threshold
binary：208×208，uint8 / bool
```

默认：

```text
unknown_prob_threshold = 0.50
```

然后以 `3×3` 椭圆核执行：

```text
binary：208×208
  ↓ morphological open，iterations=1
binary_open：208×208
  ↓ morphological close，iterations=1
binary_close：208×208
```

作用：

```text
open：尽量移除孤立小噪点
close：尽量连接相邻小孔洞/断裂区域
```

再运行 8 连通域：

```text
labels：208×208，int
stats：每个连通域的 x / y / width / height / area
```

每个连通域过滤条件：

```text
area_208 >= unknown_min_area_208
area_208 <= unknown_max_area_ratio × 208 × 208
```

当前默认：

```text
area_208 >= 4
area_208 <= 0.50 × 43,264 = 21,632
```

保留下来的每个组件 `k`：

```text
mask_208[k]：208×208，uint8
bbox_xyxy_208[k]：4 个整数
area_208[k]：标量
peak_score[k]：组件内 residual 的最大值
mean_score[k]：组件内 residual 的平均值
score[k]：当前等于 peak_score[k]
```

### 29.5 unknown mask / box 如何映射回原图

对每个未知组件：

```text
mask_208：208×208
  ↓ nearest resize
mask_original：H0×W0，bool
```

box 先转换到 832 空间：

```text
bbox_xyxy_208：[x1,y1,x2,y2]
  ↓ 每个坐标乘以 4
bbox_xyxy_832：[4x1,4y1,4x2,4y2]
```

再按原图比例：

```text
scale_x = W0 / 832
scale_y = H0 / 832

bbox_xyxy_original：4 个整数
```

## 30. known 与 unknown 的最终语义区别

| 项目 | known instance | unknown_anomaly |
|---|---|---|
| 产生方式 | YOLO 检测头 + NMS + `proto [32,208,208]` 解码 | `anom_prob [1,208,208]` 扣除 known 后连通域 |
| 类别 ID | `0..7` | `null` |
| 类别名称 | 8 个已知类别之一 | `unknown_anomaly` |
| 是否能表明具体缺陷类型 | 能，限于已知 8 类 | 不能，只代表“异常但未被已知实例覆盖” |
| score | 已知类置信度 | 当前为连通域内 `peak_score` |
| 训练来源 | 人工已知类 box/polygon | anomaly branch 的像素级监督 |
| 是否会进入标准 YOLO 混淆矩阵 | 会 | 不会，需独立 unknown 评估 |

`unknown_anomaly` 的正确业务解释是：

> 该区域没有被高置信已知类别实例覆盖，但异常分支认为它偏离已学习的监督模式；应报警、保留图像或交由人工复核。

它不是自动识别到了一个命名的新缺陷品类。

## 34. 当前限制与后续校准边界

1. **正常库规模有限**：当前 `N_ok=20`。这足以验证流水线，但未必覆盖生产中全部正常光照、材质和设备波动。
2. **教师正样本当前为零**：因为训练图 `A_208` 最高值约 `0.1394`，低于 `tau_high≈0.2797`。当前 anomaly branch 的正样本几乎完全来自人工已知缺陷实例。
3. **smoke checkpoint 不可用于业务结论**：1 epoch smoke 模型可能使 `anom_prob [1,208,208]` 大面积偏高，从而在 Phase 4 产生过多 unknown 连通域。这证明接口连通，不证明检出质量。
4. **Phase 4 阈值需独立校准**：`unknown_prob_threshold=0.50`、最小面积、最大面积和形态学核应在独立正常集与留出的未知异常集上调整。
5. **unknown 不等于新类别名称**：`unknown_anomaly` 是报警/复核对象。经人工确认并积累足够标注后，才能创建新类别并重新训练已知类主路。
6. **不要混淆两个异常体系**：`A_208` 是 Phase 2 WRN 正常库产生的离线教师分数；`anom_prob` 是 Phase 3 训练后 anomaly head 的在线输出。两者都为 `208×208`，但语义、分布和阈值不同。
